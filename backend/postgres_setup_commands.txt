# PostgreSQL Setup Commands for RAGify

## Prerequisites
- PostgreSQL must be installed and running
- psql command-line tool must be available
- You must know the PostgreSQL superuser password

## Step-by-step Setup Using Terminal

### 1. First, update your .env file with your PostgreSQL password:
```bash
# Edit the .env file to set your PostgreSQL password
# Change POSTGRES_PASSWORD=postgres to your actual password
```

### 2. Create the database:
```bash
# Connect to PostgreSQL as superuser and create the ragify database
psql -h localhost -p 5432 -U postgres -d postgres -c "CREATE DATABASE ragify WITH OWNER = postgres ENCODING = 'UTF8' LC_COLLATE = 'en_US.UTF-8' LC_CTYPE = 'en_US.UTF-8' TABLESPACE = pg_default CONNECTION LIMIT = -1;"
```

### 3. Create tables in the ragify database:
```bash
# Run the database setup script to create all tables
psql -h localhost -p 5432 -U postgres -d ragify -f database_setup.sql
```

### 4. Verify the setup:
```bash
# Connect to the ragify database and list tables
psql -h localhost -p 5432 -U postgres -d ragify -c "\\dt"
```

### 5. Run the Go migration (alternative method):
```bash
# Ensure you have the correct database credentials in .env
# Then run the Go migration to create tables
go run migrate.go
```

## Alternative: One-liner setup command:
```bash
# Create database and run migrations in one step (after updating .env)
psql -h localhost -p 5432 -U postgres -d postgres -c "CREATE DATABASE ragify WITH OWNER = postgres ENCODING = 'UTF8';" && psql -h localhost -p 5432 -U postgres -d ragify -f database_setup.sql
```

## Running the Application After Setup:
```bash
# After successful database setup, run the application
go run cmd/server/main.go
```

## Troubleshooting:
- If you get "password authentication failed", verify your PostgreSQL password in .env
- If you get "database does not exist", make sure you created the 'ragify' database first
- Make sure PostgreSQL service is running before attempting setup
- Check that the port (default 5432) matches your PostgreSQL configuration
